Tum RareはTum文字で書きます。この文法書では、本文には主にラテン文字の転写を使い、単語や例文にはTum文字を添えています。

## 書く向きと合字

Tum文字は左から右に書き、単語の間には空白を置きます。大文字と小文字の区別はなく、ラテン文字に転写するときは基本的に小文字を使います。

Tum文字には中央を通る線があり、子音と母音は線の上下を使い分けます。子音のすぐ後ろに母音が続くと、二つを組み合わせて一つの字形（合字）にします。たとえば言語名の {{text:tumrare}} は、転写では七文字ですが、Tum文字では「tu・m・ra・re」の四つの字形になります。

## 文字と発音

子音を表す文字は14種類、母音を表す文字は5種類です。基本的に一文字に一つの音が対応し、同じ母音を二つ続けて書くと長母音になります。表では、文字の右の / / に発音を示します。

### 子音

| 調音方法 | 声帯振動 | 両唇音 | 唇歯音 | 歯茎音 | 軟口蓋音 | 声門音 |
|---|---|---|---|---|---|---|
| 破裂音 | 無声 | {{text:p}} /p/ | | {{text:t}} /t/ | {{text:c}} /k/ | |
| | 有声 | {{text:b}} /b/ | | {{text:d}} /d/ | {{text:g}} /g/ | |
| 摩擦音 | 無声 | | {{text:f}} /f/ | {{text:s}} /s/ | | {{text:h}} /h/ |
| | 有声 | | {{text:v}} /v/ | {{text:z}} /z/ | | |
| 鼻音 | 有声 | {{text:m}} /m/ | | {{text:n}} /n/ | | |
| 側面接近音 | 有声 | | | {{text:r}} /l/ | | |

破裂音は、空気の流れをいったん止めてから開放する音です。{{text:p}} と {{text:b}} では両唇を閉じ、{{text:t}} と {{text:d}} では舌先を歯茎に、{{text:c}} と {{text:g}} では舌の奥を軟口蓋に付けます。どの組も、後者は声帯を震わせます。特に {{text:c}} の読みは /k/ です。

摩擦音の {{text:f}} と {{text:v}} は上の前歯と下唇の隙間に、{{text:s}} と {{text:z}} は舌と歯茎の隙間に息を通します。{{text:h}} は声門を開いて息を出します。

鼻音の {{text:m}} と {{text:n}} は、口からの空気の流れをそれぞれ両唇と歯茎で止め、鼻に通して発音します。{{text:r}} は英語の light の最初の音 /l/ に相当し、舌先を歯茎に付けて舌の横から息を通します。

### 母音

| 舌の高さ | 唇の形 | 前舌 | 後舌 |
|---|---|---|---|
| 狭母音 | 非円唇 | {{text:i}} /i/ | |
| | 円唇 | | {{text:u}} /u/ |
| 半狭母音 | 非円唇 | {{text:e}} /e/ | |
| | 円唇 | | {{text:o}} /o/ |
| 広母音 | 非円唇 | {{text:a}} /a/ | |

母音は、舌の位置、口の開き、唇の形で読み分けます。たとえば {{text:i}} と {{text:u}} はどちらも口を狭くして発音します。{{text:i}} では舌を前寄りに置き、{{text:u}} では舌を後ろ寄りに置いて唇を丸めます。

## 句読記号

| 記号 | 使い方 |
|---|---|
| {{text:.}} | 文の終わりを示します。 |
| {{text:?}} | 疑問を示します。語頭と語末に置きます。 |
| {{text:!}} | 強調や強意を示し、語頭と語末に置きます。 |

## 数字

Tum Rareでは八進法を使います。使う数字は {{text:0 1 2 3 4 5 6 7}} の八つです。たとえば十進数の2026は、八進数では {{text:3752}} と書きます。
